# GG Office

교직원·학생·학부모를 위한 경기교육 클라우드 서비스 비공식 이용 안내 사이트.

## 구성

- 모바일 우선 반응형 디자인 / 대상별 안내 / 4단계 가입 가이드
- 가입 상태에 따른 다음 단계 안내 (이용 자격 판정 아님)
- Microsoft 365, Google Workspace, Hancom Docs 안내
- 검색 (Ctrl/Cmd+K), FAQ 아코디언, 공식 사이트 링크
- 계정 입력, 서버 전송, 자가진단 저장, 분석 추적 코드 없음

## 실행 및 배포

빌드나 패키지 설치 없이 `index.html`을 브라우저로 열 수 있습니다.
GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

파일: `index.html`(내용), `styles.css`(디자인), `app.js`(상호작용), `favicon.svg`.
폰트는 Google Fonts에서 불러오며, 실패하면 시스템 글꼴로 표시합니다.
